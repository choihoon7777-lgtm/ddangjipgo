# 개발포커스 분양·청약 운영 체크리스트

## 실제 공식 데이터 수집
- 출처: 한국부동산원 청약홈 분양정보 조회 서비스 https://www.data.go.kr/data/15098547/openapi.do
- 제공: APT, 무순위·잔여세대, 임의공급. 공급유형+단지관리번호+공고번호로 중복을 막는다.
- 조회: GET /api/focus-housing 는 검증된 DB 자료만 제공하며, 사용자의 페이지 방문 때 공식 API에 반복 요청하지 않는다.
- 자동수집: GET /api/focus-housing-sync. 한국 기준 최근 120일 공고와 주택형별 최고 분양금액을 확인한다. 수집 결과가 불완전하면 partial 처리한다.
- 수집이력을 df_housing_sync_runs에 기록하고, 변경 전 내용을 df_housing_offer_versions에 보관한다. 수집에 실패한 가격은 기존 검증값을 보존한다.
- 관리자 점검 화면: /focus-admin/housing. 키 원문과 임의 실행 버튼 없이 설정/공고건수/최근 동기화만 공개한다.

## 환경 설정 (서버 관리자만 실행)
- 기존 DATA_GO_KR_SERVICE_KEY는 유지한다. 해당 청약홈 API의 활용 승인이 실제로 적용됐는지 API 응답을 확인해야 한다.
- SUPABASE_SERVICE_ROLE_KEY: Vercel 서버 전용 민감값으로 등록. 브라우저/저장소/채팅에 절대 기록하지 않는다.
- CRON_SECRET: 랜덤한 서버 실행 인증값으로 등록. 관리자 상태 페이지는 값을 노출하지 않는다.
- Vercel Preview 환경에서 인증된 cron GET /api/focus-housing-sync를 우선 검수한다. 200 성공 응답 이후 df_housing_offers 레코드가 증가했는지 확인한다.
- Vercel Hobby cron은 일 1회 제한, 실행 시각 오차가 가능하다. 운영 cron은 운영배포 승인 전 실제로 가동되지 않는다.

## 실제 데이터 검수 완료기준
1. 수집 성공 + 최신 건수 양수 + 가격 포함 건수 양수 + 연속 2회 실행해 중복이 없어야 한다.
2. 공식 입주자모집공고 최소 20건을 표본으로 각 날짜, 공급세대수, 59㎡·84㎡ 최고금액을 대조한다.
3. 정정공고 발생시 이전 스냅샷과 변경 항목을 조회할 수 있어야 한다.
4. 모델별 가격이 없는 공고는 미확인으로 노출하고, 임의 금액은 생성하지 않는다.
5. iOS·Android 모바일 상세/검색/필터/빈화면/재시도 검수.
6. 운영 배포는 사용자의 명시적 지시가 있을 때만 진행한다.

## 주의
- API 개발단계 자동승인과 실제 운영단계 심의 권한은 다를 수 있다. 운영 전 제공기관의 최신 이용 조건을 확인한다.
- 원문은 공식 청약홈 페이지에서 최종 검증하고, 발코니 확장 및 옵션 비용은 최고 분양금액에 포함됐다고 추정하지 않는다.
